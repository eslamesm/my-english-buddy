## Semantic mappings
- Days of the week, today/tomorrow/yesterday, week, and month names use the calendar-clock illustration; the displayed vocabulary label supplies the specific day/month name.
- Spring, summer, fall, winter use distinct seasonal illustrations.
- Morning, noon, evening, night use distinct time-of-day scenes.
- Breakfast/lunch/dinner use meal/home scenes; school/study/books/playground/family picnic use matching scenes.

## Notes
The source artwork was a 4x4 generated illustration sheet. Each tile was cropped into a separate 512x512 RGBA PNG. These are independent files; the original contact sheet is not used as a vocabulary asset.
