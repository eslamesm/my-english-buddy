# Curriculum progression acceptance, 24 November 2026

Development-only cumulative patch. No live deployment or GitHub write.

## Approved exam gate

- Saved three-star mastery of every distinct AVAILABLE word unlocks a dedicated progression test, never the next path by itself.
- Twenty distinct sampled words, or every available word if fewer. Questions are spread across available units; Primary 1 grade advancement balances the two terms. Term 1 must pass its own test first, even if legacy stars already cover term 2.
- Picture-to-word and audio-to-word questions. No hint, correctness color/sound, current score or correct-answer reveal during the test. Listening questions can be replayed. Answer choice locks, with an explicit next/submit control.
- Ninety percent correct is required, using the exact integer fraction rather than rounded display percentage. Thus18/20 passes and17/20 fails. A small pool of fewer than10 questions requires all correct.
- Failed test leaves the next path closed and preserves stars, learning data, reviews and existing statistics. Every wrong word must be reviewed: completed audio playback followed by selecting the shown word. No skipping review by opening or leaving the screen. Audio failure does not count as reviewed.
- After review, a fresh randomized attempt is available without an attempt limit or time penalty. A new sample can overlap a previous one; it is not promised to be disjoint.
- Ordinary general/unit exams, old lastExam values and parent progression approval cannot substitute for this test.
- Dedicated attempt and pass records bind the child, identity epoch, source/destination grade and term, available content and policy version. Navigation, profile switching, changed scope and stale controls cannot award pass credit. Duplicate finish and detached next controls are rejected. Reload preserves completed results and unfinished review requirements, but an interrupted test starts again without pass credit.
- Automatic mode applies a valid pass and shows an in-app notice with undo. Parent mode requires BOTH the pass and parent approval. Old profiles still need the one-time policy choice; new profiles default to automatic. Undo pauses auto progression and preserves learning data. Prior already-open paths are not retroactively revoked.
- Primary 1 term 2 curriculum launch is locked until term 1 progression is passed. Earlier allowed grades remain available for review. Explicit parent starting-grade/access setup remains separate, unchanged authority.
- Final available grade gets a completion result only after passing its test. No invented next grade or school certification.
- Storage failure blocks result credit or rolls back the attempted progression fields; it does not delete learning history.

## Scope and limits

This is a vocabulary recognition/listening sample from available app content, not a complete curriculum examination, writing assessment, speaking assessment or school certification. KG1/KG2 currently have term1 only. Grades above Primary1 contain selected supporting vocabulary. Content references are2025/26; expansion to the intended edition remains separate.

No physical-device microphone test or human pronunciation verdict. Four earlier recordings still await listening review. The new review flow was tested with actual browser audio completion, not a human judgement of pronunciation.
